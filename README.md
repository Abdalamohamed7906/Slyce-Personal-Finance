# Splyce 💰

A full-stack budgeting app that automatically splits your paycheck using the **60/20/20 rule** (needs / wants / savings), designed to help young people build better money habits.

> 🚧 **Status:** In progress

## Features
- Split-calculation engine: enter a paycheck and get your 50/30/20 breakdown
- User accounts with JWT authentication and hashed passwords
- Paycheck history saved per user, so you can track splits over time
- Short, personalised financial tips generated by an LLM based on your split
- Lightweight HTML/JS frontend

## Tech Stack
- **Backend:** Python, FastAPI
- **Database:** SQLite
- **Auth:** JWT, hashed passwords
- **AI:** [LLM provider] API
- **Frontend:** HTML, JavaScript
